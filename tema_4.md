### Напишите функцию, которая на вход получает кортеж '**kwargs' и при помощи цикла выводит значения, поступившие в функцию. На скриншоте ниже указаны два варианта вызова функции с '**kwargs' и два варианта работы с данными, поступившими в эту функцию. Комментарии в коде и теоретическая часть помогут вам разобраться в этом нелегком аспекте. Вызовите функцию используя 'точку входа'.

```python
def main(**kwargs):
    for i in kwargs.items():
        print(i[0], i[1])
        print() 
    for key in kwargs:
        print(f"{key} = {kwargs[key]}")
if __name__ == '__main__':
    main(x=[1, 2, 3], y=[3, 3, 0], z=[2, 3, 0], q=[3, 3, 0], w=[3, 3, 8])
    print()
    main(**{'x': [1, 2, 3], 'y': [3, 3, 0]})
```

## Самостоятельная работа №1
### Дайте подробный комментарий для кода, написанного ниже. Комментарий нужен для каждой строчки кода, нужно описать что она делает. Не забудьте, что функции комментируются по-особенному.

```python
from datetime import datetime  # импорт класса datetime для замера времени
from math import sqrt  # импорт функции sqrt для вычисления квадратного корня

def main(**kwargs):  # объявление функции main, принимающей именованные аргументы
    for key in kwargs.items():  # итерируем пары (ключ, значение)
        result = sqrt(key[1][0]**2 + key[1][1]**2)  # вычисляем sqrt(x^2 + y^2) 
        print(result)  # вывод результата
if __name__ == '__main__':  # проверка выполняется ли код в main файле
    start_time = datetime.now()  # сохраняем текущее время перед запуском main
    main(  # вызов функции main с набором именованных аргументов
        one=[10, 3],  # передаем аргумент 'one' со значением [10, 3]
        two=[5, 4],  # передаем аргумент 'two' со значением [5, 4]
        three=[15, 13],  # передаем аргумент 'three' со значением [15, 13]
        four=[93, 53],  # передаем аргумент 'four' со значением [93, 53]
        five=[133, 15],  # передаем аргумент 'five' со значением [133, 15]
    )  # конец передачи аргументов
    time_costs = datetime.now() - start_time  # вычисляем затраченное время выполнения
    print(f"Время выполнения программы {time_costs}")  # выводим время выполнения
```
